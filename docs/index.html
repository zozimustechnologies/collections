Everything Edge Collections had — and more

Save any type of web content into named, colour-coded collections. All stored locally, no account needed.

🔗

Save Pages & Links

One click saves the current page's URL, title, and favicon into any collection. Or right-click any link to add it directly.

📋

Capture Quotes

Highlight text on any page and use the interactive selection mode to save the exact quote with context into your collection.

📷

Save Images

Right-click any image on a page to add it, or paste a direct image URL. The extension previews the image inside the card.

📝

Write Notes

Add freeform text notes to any collection — great for ideas, summaries, or reminders attached to your research.

🎨

Colour-Coded Collections

Create as many collections as you need. Each has a custom colour for quick visual identification in your sidebar.

🛠

Context Menu Integration

Right-click anywhere — on a page, a link, or an image — to send content directly to any collection without interrupting your flow.

Your data stays yours

100% local storage. Nothing ever leaves your browser.

🔒

100% Local

All collections are stored in your browser using the local storage API. No servers, no cloud, no sync.

🚫

No Tracking

Zero analytics, zero cookies, zero data collection. We have no idea who you are and we like it that way.

📦

No External Scripts

Everything runs inside the extension. No CDNs, no remote code, no third-party requests.

👀

Open Source

Every line of code is on GitHub. Audit it yourself — we have nothing to hide.

Get started in seconds

Install the extension

Get it from the Edge Add-ons store and pin it to your toolbar.

Open the side panel

Click the Collections icon in your toolbar. The panel opens in the browser sidebar, always within reach.

Create a collection

Tap the + button, name your collection, pick a colour, and you’re ready to start collecting.

Save content

Right-click links, images, or selected text — or use the in-panel FAB menu to add the current page, a quote, image, or note.
